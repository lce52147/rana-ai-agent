# Rana Vision relationship references

This directory contains local reference material used to compare a Discord image with people already present in Rana's relationship graph.

- `source/`: official character artwork downloaded from the source URL recorded in `../character_catalog.json`.
- `atlas-core.png`: Rana, MyGO!!!!!, RiNG/SPACE, Mutsumi, and Sakiko.
- `atlas-extended.png`: other Ave Mujica and cross-band acquaintances.

The atlas is visual evidence only. Relationship meaning comes from the workspace lore catalog, and the final response is generated by OOGG.

Rebuild the atlases with:

```powershell
powershell -ExecutionPolicy Bypass -File .\extensions\rana-vision\scripts\build_character_atlases.ps1
```
