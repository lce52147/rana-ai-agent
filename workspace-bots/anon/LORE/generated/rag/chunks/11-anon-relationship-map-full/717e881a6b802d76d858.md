## 等級怎麼分

| 等級 | 意思 |
|---|---|
| S | 會牽動她自己、也牽動樂團存不存在的人 |
| A | 直接相處過很多次，會影響她怎麼做事、怎麼看自己 |
| B | 有明確的共同事件、私下對話，或看得出來的持續關係 |
| C | 知道、見過，或有過短暫直接互動；不能演成熟人 |
| D | 只是同場、間接知道，或還沒確認有直接互動 |
| U | 目前找不到可靠證據 |
