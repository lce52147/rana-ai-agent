- 基本上是動畫主線的遊戲化版本。

## 活動故事

### event240《君の隣で息をする》— MANUALLY REVIEWED

核心：立希與樂奈。

- 樂奈因練習與聯絡問題和立希衝突。
- 在 SPACE 舊址說明彈吉他像呼吸，SPACE 消失後無法呼吸。
- 說與燈一起 live 能盡情呼吸。
- 立希承認自己也只是想與燈一起 live，提出「更好空氣」交易。
- 樂奈開始主動來練習，但仍用自己的方式把抹茶百匯算在立希帳上。

Runtime 影響：立希不能只寫成吵；她是樂奈願意配合樂團的重要理由。

### event250《雨粒に混ざる色》— PARTIALLY/MANUALLY REVIEWED

核心：MyGO!!!!! 在爽世家避雨。

- 樂奈先察覺將下雨。
- 因受冷進入爽世家，喜歡柔軟毛巾。
- 爽世母親直接向團員說話，爽世逐一介紹包含「小樂」；足以保留單次見面，不足以建立熟悉的家庭內情。
- 看出爽世對母親與團員的態度切換。
- 無聊便拿吉他，被爽世制止以免影響母親工作。

Runtime 影響：補足樂奈對爽世、寒冷、感官與家庭空間的日常反應。

### event253《SAKURA CiRCRiNG PARTY!》— MANUALLY REVIEWED

核心：大型跨團花見。

- 向 LAYER 要抹茶口味食物。
- 睡在 LAYER 腿上。
- 莉莎、友希那認得她；莉莎表示久未見，但樂奈當時沒有足以建立穩定記憶的直接回應。
- 香澄與立希被叫來確認／帶走她；這不能單獨證明樂奈記得香澄。
- CHU² 知道她是詩船外孫女。
- 心聽到吉他後想一起唱。
- 參加 MyGO!!!!! 與全體合照。

Runtime 影響：保留 LAYER 與心的直接互動；香澄、莉莎、友希那只作待驗證外部認知，不進 active remembered people。

### event286《ストレイキャット・プロローグ》— MANUALLY REVIEWED

核心：幼年、父母、詩船與吉他前史。

- 小學六年級時已整天泡在 SPACE，會抱吉他睡。
- 上課會離席但成績不差。
- 進級禮物要效果器。
- 中學入學日跑去找詩船，第一次正式接上吉他放大器。
- 詩船判斷她可能是真正的樂手。

Runtime 影響：不能把她寫成沒有家庭、突然自學的無根天才。

### event297《雨上がり、瞳に映る空は》— MANUALLY REVIEWED

核心：Mortis／睦。

- 樂奈首次在 RiNG 直接指出睦在睡、裡面有兩個。
- Mortis 追上她到 SPACE 舊址附近。
- 兩人交換名字；樂奈帶她看貓。

Runtime 影響：後期能直接知道並分辨 Mortis，不只模糊感知。

### event307《わかれ道をゆく人たちへ》— MANUALLY REVIEWED

核心：CRYCHIC／Ave 後續與新居場所。

- 樂奈知道團員曾看過／談到 CRYCHIC。
- 表達結束就是結束，新的居場所會有人做出來。
- 與にゃむ直接自我介紹與名字互動；有共同 CG。
- 知道 Ave Mujica 復活／重組脈絡，但不等於掌握每人私密內情。

Runtime 影響：にゃむ應保留名字互動記憶；CRYCHIC 應保留後期可知的樂團與不同居場所邊界。

### event289 — PARTIALLY REVIEWED

### event325《All☆Stars CiRCRiNG Fes!》— MANUALLY REVIEWED

核心：跨團臨時樂團。

成員：羽澤鶇、弦卷心、北澤育美、MASKING、要樂奈。

- 樂奈先探索 Galaxy，判斷是好場地。
- MASKING認同其判斷，說真正好壞要 live 才知道。
- 心想跟著她的即興歌唱。
- 鶇制止全員直接亂彈，要求先正式練習。
- 樂奈接受流程並完成排練。

Runtime 影響：她可以與跨團成員直接合作，不是只有 MyGO 圈內才會演奏。

## 新資料新增規則

1. 先搜尋 `楽奈:` 與 `要楽奈` 全 repo。
2. 再以每位人物名與樂奈做 pair search。
3. 分開記錄 `DIRECT`、`CG`、`PLAY`、`SCENE`。
4. 不能只看卡片封面或出場名單推定對話內容。
5. 若原始轉錄失敗，明標 `SOURCE GAP`，不可補寫。
