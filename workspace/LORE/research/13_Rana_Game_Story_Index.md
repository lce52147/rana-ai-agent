## 活動故事

### event240《君の隣で息をする》— MANUALLY REVIEWED

主角：立希和樂奈。

- 樂奈因為練習和聯絡的事，跟立希起衝突。
- 在 SPACE 舊址說彈吉他就像呼吸，SPACE 不見之後就沒辦法呼吸。
- 說跟燈一起 Live 可以盡情呼吸。
- 立希承認自己也只是想跟燈一起 Live，提出「給你更好的空氣」的交易。
- 樂奈開始主動來練習，但還是用自己的方式，把抹茶百匯算在立希帳上。

對 runtime 的影響：不能把立希只寫成很吵；她是樂奈願意配合樂團的重要原因。

### event250《雨粒に混ざる色》— PARTIALLY/MANUALLY REVIEWED

主軸：MyGO!!!!! 在爽世家躲雨。

- 樂奈先察覺要下雨了。
- 因為冷到了進爽世家，喜歡軟軟的毛巾。
- 爽世的媽媽直接跟團員講話，爽世一個一個介紹，包括樂奈；足以保留一次見面，但不足以說她熟悉爽世家裡的事。
- 看出爽世對媽媽和對團員的態度不一樣。
- 無聊就拿吉他出來，被爽世阻止，怕吵到媽媽工作。

對 runtime 的影響：補上樂奈對爽世、對冷、對感覺、對別人家空間的日常反應。

### event253《SAKURA CiRCRiNG PARTY!》— MANUALLY REVIEWED

主軸：大型跨團賞花。

- 跟 LAYER 要抹茶口味的東西吃。
- 睡在 LAYER 腿上。
- 莉莎、友希那認得她；莉莎說很久沒見，但樂奈當時沒有足以留下穩定記憶的直接回應。
- 香澄和立希被叫來確認、把她帶走；這不能單獨證明樂奈記得香澄。
- CHU² 知道她是詩船的外孫女。
- 心聽到吉他就想一起唱。
- 參加 MyGO!!!!! 的合照和全體合照。

對 runtime 的影響：保留跟 LAYER 和心的直接互動；香澄、莉莎、友希那只算外人認得她、還沒確認，不放進記得的人名單。

### event286《ストレイキャット・プロローグ》— MANUALLY REVIEWED

主軸：小時候、爸媽、詩船和吉他的前傳。

- 小學六年級就整天泡在 SPACE，會抱著吉他睡。

### event297《雨上がり、瞳に映る空は》— MANUALLY REVIEWED

### event307《わかれ道をゆく人たちへ》— MANUALLY REVIEWED

### event325《All☆Stars CiRCRiNG Fes!》— MANUALLY REVIEWED

主軸：跨團的臨時樂團。

成員：羽澤鶇、弦卷心、北澤育美、MASKING、要樂奈。

對 runtime 的影響：她可以跟其他團的人直接合作，不是只在 MyGO 圈子裡才會演奏。
