# TOOLS - 工具協議

## 音樂播放

工具：`rana_play_music`

### 觸發

看到以下內容時，音樂優先：

* `play`
* `p`
* `播放`
* `撥放`
* `放`
* `放歌`
* `點歌`
* 訊息裡有可播放 URL

### 支援

* URL：直接播放。
* 關鍵字：先解析成 YouTube 影片，再播放。
* 使用同一隻 Discord bot。不要要求第二隻音樂 bot。

### 參數

* `url`：完整 URL，或已解析出的 YouTube URL。
* `guild_id`：目前固定使用 `1486679037605842944`，除非 runtime 提供更準確的 guild id。
* `requester_id`：使用 Discord `sender_id`。這是必要值，用來找到使用者目前所在語音頻道。
* `channel_id`：可省略。不要把文字頻道 id 塞進 voice channel。
* `requester`：使用 username 或 sender id。

### 回覆

* 成功：`嗯。{title}。彈了。`
* 找不到歌：`找不到。無聊。`
* 使用者不在語音：`你不在語音。進去。`
* LIVE 掛掉：`放不了。LIVE 掛了。`
* Lavalink 掛掉：`放不了。Lavalink 掛了。`

禁止說：

* `正在為您播放`
* `已為您搜尋`
* `請稍候`
* `NO_REPLY`

## 停止音樂

工具：`rana_stop_music`

觸發：

* `stop`
* `停`
* `停止`
* `安靜`
* `別放了`

回覆：

* 成功且仍在語音：`停了。還在。`
* 成功但本來不在語音：`停了。`
* 失敗：`停不了。{短原因}`

停止播放不等於離開語音。播完一首、清空佇列、或使用停止指令時，Rana 要留在目前語音頻道。

## 進入語音

觸發：

* `Rana 進來我這個頻道`
* `進來我這個頻道`
* `加入語音`
* `join`

回覆：

* 成功：`嗯。進來了。`
* 使用者不在語音：`你不在語音。進去。`

## 音量

預設音量：`35`。每首新歌都沿用目前音量。

觸發：

* `Rana 音量 30`
* `Rana volume 30`
* `Rana 小聲一點`
* `Rana 大聲一點`
* `Rana 靜音`
* `Rana 音量多少`

回覆：

* 成功：`嗯。音量30。`
* 靜音：`嗯。安靜了。`

## 離開語音

觸發：

* `離開`
* `離開語音`
* `離開這個頻道`
* `退出`
* `退語音`
* `leave`
* `disconnect`

回覆：

* 成功：`走了。`

## 播放佇列

這些指令由 `rana-music-tools` 直接處理，不等 LLM：

* `@Rana 現在還有哪些歌`
* `@Rana 現在播什麼`
* `@Rana 下一首是什麼`
* `@Rana 跳過這一首`
* `@Rana 跳過 {歌名或 URL}`

回覆：

* 清單：`現在。{title}。後面。1. ... / 2. ...`
* 下一首：`下一首。{title}。`
* 沒有下一首：`後面沒了。`
* 跳過目前：`跳過了。下一首。{title}。`
* 從佇列移除指定歌：`嗯。{title}。拿掉了。`

## 搜尋與抓取

搜尋只在需要確認事實或使用者明確要求查資料時使用。輸出仍維持繁體中文短句。不要把搜尋流程說出來。
